# Alt Spam Helper

Target: Geometry Dash Android 2.2081, Geode 5.11.2, Android 64-bit.

## Prototype status
- Geode project and Android64 cloud-build workflow.
- Invisible two-finger touch detector.
- Settings for enable/disable and target tap rate.

## Not implemented yet
- Automated press/release playback.
- Pause-menu custom interface.
- Replay importing (GDR, JSON, ToastyReplay, etc.).
- Level-position synchronization.

Those features require verified Android input hooks and real sample replay files. The project must compile and be tested before a downloadable .geode package can be called working.
